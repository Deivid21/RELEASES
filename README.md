# Deivid_21's Builds

Mirror of my builds for Motorola devices: LineageOS, Evolution X and more. Each release has the ROM zip and the partition images needed to flash it.

📱 Device pages, official builds and install guides: **[Deivid21 Hub](https://deivid21.github.io/devices/)**  
📢 Updates: **[Telegram @Deivid21Hub](https://t.me/Deivid21Hub)**

**Build types**

- **Last Nightly**: the last official LineageOS nightly for that version.
- **Unofficial**: my own builds, signed with dev-keys.
- **Test Build**: work in progress; expect bugs and send logs.
- **EOL**: project no longer maintained.
